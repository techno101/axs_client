# Client Project Context

The public site lets customers read current venue/CMS information and, when server capability permits, select availability, acquire a hold, enter details, create a booking and navigate to hosted checkout. Authoritative booking state comes from the API; redirects are never confirmation.

Current public field defaults remain “Field 1” and “Field 2” until the owner supplies verified content. Address, contacts, policies, legal text and final photography are intentionally pending.
