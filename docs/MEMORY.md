# Client Memory

`axs_client` is an independent Vercel public website/API consumer. It has live typed v1.3.0 contract consumption for public configuration, fields, availability, holds, booking, status and CMS content. It owns no server authority.

The Phase 7 baseline recognizes the server-authoritative disabled online-payment capability. While false, visitors can review fields/times/prices but no public mutation should be attempted. Result pages poll authoritative server state and browser redirects are not payment proof.

Phase 9 completes optional accounts, verified email/Google sign-in, documents/email/PDF, SEO and privacy-safe analytics readiness. Keep owner-pending contacts/legal/policies/media visibly pending until approved.
